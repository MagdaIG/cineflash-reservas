# cineflash reservas

Aplicación web de reservas de cine desarrollada con HTML, CSS, Bootstrap y jQuery. Permite seleccionar películas, completar un formulario de reserva y visualizar una confirmación mediante modales personalizados. Proyecto enfocado en la interacción con el DOM y validaciones básicas.

## Tech Stack

HTML5, CSS3, JavaScript and Bootstrap

## Getting Started

```bash
git clone https://github.com/MagdaIG/cineflash-reservas.git
cd cineflash-reservas
Open index.html in your browser
```
